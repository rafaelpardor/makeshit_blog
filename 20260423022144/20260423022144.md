
# Spring interview questions

1. Why does a Spring Boot app start successfully but fail after a few minutes?  
	- A Spring Boot app starting fine but failing minutes later usually means the problem is **runtime, not startup configuration**. Startup validates wiring; it doesn’t guarantee stability under load, scheduling, or external dependencies.

49. Why does @ConfigurationProperties fail silently?  
	- `@ConfigurationProperties` can fail silently because if the configuration values are incorrect but not missing, the application may not throw errors, leading to unexpected behavior without any alerts or crashes. This can result in issues like misrouted traffic or timeouts that are hard to diagnose.
