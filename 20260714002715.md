# Lambda Expressions

Lambda expressions allow developers to write concise, functional-style code by representing anonymous functions. They enable passing code as parameters or assigning it to variables, resulting in cleaner and more readable.

- lambda expressions implement a **functional interface**
- Enable passing code as data (method arguments)
- It can access only final or effectively final variables from the enclosing scope.
- Lambdas cannot throw checked exceptions unless the functional interface declares them.
